# Multi-Cloud Storage Mesh System (CloudFusion)

Zero-Trust Multi-Cloud Virtualized Storage Mesh integrating AWS S3, Google Drive, Dropbox, MEGA, and Microsoft OneDrive into a unified 52 GB encrypted storage pool.

## 📖 Key Documentation & Defense Guides
- **[System Architecture & Communication Guide](SYSTEM_COMMUNICATION_AND_ARCHITECTURE_GUIDE.md)**: Detailed end-to-end communication steps between Frontend, Backend, Database (PostgreSQL/Prisma), and the 5 Cloud Providers, complete with sequence diagrams and defense Q&A.
- **[Project Status & Verification Guide](PROJECT_STATUS.md)**: Live verification status, test scripts, and running instructions.

## 🚀 Quick Start

### 1. Backend
```bash
cd backend
npm install
npm run dev
```

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```

Open browser at: `http://localhost:3000`
